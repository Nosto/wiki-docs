# Introduction

{% hint style="warning" %}
You are reading the **NextGen Documentation**

**NextGen widgets** are a new and improved way to display UGC content onsite.&#x20;

From September 23rd 2025, all new widgets created will be NextGen.

Please check your widget version on the **Widget List page** to see if it is a **Classic** or **NextGen** widget.

You can read the [Classic Widget Documentation](../widgets/) here.
{% endhint %}

The new **NextGen Widgets** are designed to deliver faster, more engaging onsite experiences. With a focus on performance and flexibility, they bring:

* **Improved onsite performance** for quicker load times and smoother interactions.
* **Modern, responsive templates** that align with today’s eCommerce design standards.
* **Enhanced video capabilities**, making it easier to showcase rich, shoppable content.

To help you get started:

* Explore the [**API Documentation**](https://widget-ui.stackla.com/docs/index.html) for technical details.
* Use the [**Practical Guides**](https://docs.nosto.com/ugc/guides/widgets-nextgen) to learn how to build and customize NextGen Widgets for your store.

NextGen Widgets are built to help you create immersive customer journeys while ensuring your site remains fast and conversion-focused.
