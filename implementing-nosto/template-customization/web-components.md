# Web components

For advanced use cases Nosto also offers a dedicated suite of web components that extend static markup with logic.

More info about Nosto's own web components is available [here](https://github.com/Nosto/web-components)

Nosto plays also well with other web component libraries and we encourage implementations to utilize web components to enhance static HTML markup with logic and as a mechanism to plug external libraries onto your page.

Recommended libraries
* [Lit](https://lit.dev/) 
* [Stencil](https://stenciljs.com/)
* [Shoelace](https://shoelace.style/)
* [Swiper web component](https://swiperjs.com/element)
