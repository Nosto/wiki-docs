# Creating a widget from the gallery

{% hint style="warning" %}
You are reading the NextGen Documentation

NextGen widgets are a new and improved way to display UGC content.&#x20;

On Oct 1st, all widgets created will be NextGen.

Please check your widget version on the Widget List page to see if it is **Classic** or **NextGen** widget.

You can read the [Classic Widget Documentation](../../../onsite-widgets/) here.
{% endhint %}

**Creating a premade template**

1\) Click the Touchpoints > Widgets link to access the Widgets screen.

<figure><img src="../../../../.gitbook/assets/image (3).png" alt="" width="127"><figcaption></figcaption></figure>

2\) Press the _Create New Widget_ button

<figure><img src="../../../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

3\) Choose your widget of choice from the gallery\


<figure><img src="../../../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

4\) Enjoy your new widget!
