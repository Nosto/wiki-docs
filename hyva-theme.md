# Hyvä Theme

### Overview

Upon installation, Nosto automatically adds product recommendation elements to your Hyvä-powered store, ensuring a smooth and hassle-free experience without requiring any manual setup.

### Key Features

* **Automatic Integration**: Once installed, the Nosto extension will automatically insert product recommendation elements into your Hyvä theme store.
* **Zero Manual Setup**: No additional configuration is needed—everything works right out of the box.
* **Seamless Performance**: The integration is optimized to work efficiently within the Hyvä ecosystem.
