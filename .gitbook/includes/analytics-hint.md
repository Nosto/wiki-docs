To analyze user behavior you need to implement tracking. This can be achieved in two different ways, depending on the integration environment:

* [JavaScript library](../../implementing-nosto/implement-search/search/#search-1) (recommended - more convenient, but requires a JavaScript environment).
* [GraphQL API](../../implementing-nosto/implement-search/implement-search-using-api/analytics-ab-testing.md) (works anywhere).
